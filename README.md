# Reyn

## The app

Every since the original beer app back in 2006 I wanted to make my own novelty app but couldn't come up 
with an idea. Until one day I realized there was no way to make it rain money in a digital way. That's how Reyn was born!
And yes, the app is on the stores. Somehow it got through the approvals (still waiting on Apple).

[Play store listing here](https://play.google.com/store/apps/details?id=com.nrsdev.reyn)

## Future for the app

Linking between users via QR code would be a cool feature so you can direct the rain to a specific person.
